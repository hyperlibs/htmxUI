Installation

HTMXUI is not a dependency you install via NPM. It is a collection of HTML, CSS, and lightweight JS snippets that you copy and paste directly into your project.

1. Install Tailwind CSS

HTMXUI uses Tailwind CSS for all styling. Ensure you have Tailwind set up in your project.

npm install -D tailwindcss
npx tailwindcss init

2. Include HTMX and HTMXUI Extensions

Add the base HTMX script, along with our ultra-lightweight htmx-bolt.js for zero-bloat client-side reactivity.

<script src="https://unpkg.com/htmx.org@2.0.4"></script>
<script src="/path/to/htmx-bolt.js"></script>

(Download htmx-bolt.js from the public directory of the repository).

3. Setup CSS Variables (Theming)

Add these CSS variables to your global stylesheet to power the dynamic theming system.

@layer base {
  :root {
    --background: 0 0% 100%;
    --foreground: 222.2 84% 4.9%;
    --card: 0 0% 100%;
    --card-foreground: 222.2 84% 4.9%;
    --primary: 221.2 83.2% 53.3%;
    --primary-foreground: 210 40% 98%;
    --muted: 210 40% 96.1%;
    --muted-foreground: 215.4 16.3% 46.9%;
    --border: 214.3 31.8% 91.4%;
    --input: 214.3 31.8% 91.4%;
    --ring: 221.2 83.2% 53.3%;
    --radius: 0.5rem;
  }
}

4. Copy and Paste Components

Browse the components in the sidebar, find the one you need, and copy the raw HTML into your templates. Use standard hx-post, hx-get, and hx-target attributes to hook them up to your backend!
