Installation

Get HTMXUI running in your project in under 2 minutes.

Prerequisites

HTMXUI is intentionally lightweight, non-invasive, and engine-agnostic. Before getting started, ensure your environment provides:

Tailwind CSS

Tailwind CSS (v3 or v4) configured in your build toolchain or via CDN.

Any HTML Backend

Any server backend that returns HTML (Python, Go, PHP, Bun, Rust, etc.).

No NPM Dependency

Zero NPM packages or complex client build steps are required for HTMXUI itself.

Step 1 — Include the Core Scripts

Add the base HTMX library and the HTMXUI client-side extensions into your base template layout: 

<!-- HTMX Core -->
<script src="https://unpkg.com/htmx.org@2.0.4"></script>

<!-- HTMXUI Reactive Engine -->
<script src="/htmx-bolt.js"></script>

<!-- Optional: In-Memory Search Engine -->
<script src="/htmx-flash.js"></script>

<!-- Optional: Visual Canvas Engine -->
<script src="/htmx-canvas.js"></script>
Note: htmx-bolt.js is the only required extension (~2KB). Flash and Canvas are optional and add zero overhead if not used.

Step 2 — Setup Tailwind CSS Theming

HTMXUI uses CSS custom properties for theming, enabling effortless customization and seamless dark mode support. Add the following CSS variables block to your global stylesheet: 

@layer base {
  :root {
    --background: 0 0% 100%;
    --foreground: 222.2 84% 4.9%;
    --card: 0 0% 100%;
    --card-foreground: 222.2 84% 4.9%;
    --primary: 221.2 83.2% 53.3%;
    --primary-foreground: 210 40% 98%;
    --muted: 210 40% 96.1%;
    --muted-foreground: 215.4 16.3% 46.9%;
    --border: 214.3 31.8% 91.4%;
    --input: 214.3 31.8% 91.4%;
    --ring: 221.2 83.2% 53.3%;
    --radius: 0.5rem;
    --accent: 210 40% 96.1%;
    --accent-foreground: 222.2 47.4% 11.2%;
    --destructive: 0 84.2% 60.2%;
    --destructive-foreground: 210 40% 98%;
  }
}

Step 3 — Copy Components

HTMXUI follows a copy-paste model. Instead of importing complex packages, you own the markup completely.

Browse the sidebar, find a component, and copy the HTML markup directly into your backend templates. Replace placeholders with your template variables (Jinja2, Go templates, Blade, ERB, etc.).

Template Integration Examples:

  • Python (Jinja2 / Django): Insert directly into .html templates and bind context variables.
  • Go (html/template / Templ): Paste into standard Go template blocks or reusable component functions.
  • PHP (Laravel Blade): Paste into .blade.php views or anonymous Blade components.
  • Bun / Node / Rust: Embed into any SSR template engine with zero compilation pipeline required.

Step 4 — Add Reactivity (Bolt)

When you need instant client-side interactivity without a round-trip to the server, use Bolt: 

<div hx-ext="reactive" hx-state='{ "count": 0, "open": false }'>
  <button hx-action="count++">Clicked: <span hx-text="count">0</span></button>
  <button hx-action="open = !open">Toggle</button>
  <div hx-show="open" class="mt-4 p-4 border rounded">I am reactive!</div>
</div>

No build step. No JSX. No Virtual DOM. Just HTML attributes. Bolt handles localized reactive state natively in ~2KB of vanilla JavaScript.

Architecture Overview

HTMXUI provides a layered architecture that pairs the server-driven simplicity of hypermedia with client-side hyperreactivity:

Application Layer
Your Templates & Domain Components
Jinja2, Go templates, Blade, JSX-less SSR, Custom Logic
Composition & Layout System
7 Layout Primitives
Layout Page, Web, Block, Grid, Scaffold, Canvas & Print
Hyperreactive Layer
Bolt + Flash + Canvas
Instant local state, 0ms in-memory search & interactive node canvas
Enhanced Hypermedia Core
htmx Foundation
Declarative requests, targeted DOM swapping, SSE & WebSockets
