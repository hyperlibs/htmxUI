Introduction

Beautifully designed components that you can copy and paste into your HTMX apps. Accessible. Customizable. Open Source.

What is HTMXUI?

HTMXUI is a massive collection of UI components designed specifically for the HTMX ecosystem. Instead of installing an NPM package or adding a complex Virtual DOM to your app, you simply copy and paste the HTML into your own project templates.

This means you have full control over the code. There are no black-box abstractions. You decide how the component interacts with your backend.

Philosophy

  • HTML First: Everything is built with standard HTML tags and CSS.
  • Zero NPM Bloat: No React, no Vue, no node_modules required for logic.
  • Tailwind CSS: Beautiful, utility-first styling by default.
  • Server-Driven: Designed to work seamlessly with hx-get and hx-post.
  • Hyper-lean Extensions: For client-side state, we provide 2KB native JS extensions like htmx-bolt.js.
