## 🛠️ How to Install in Your Browser

### Option A: Install via ZIP (Chrome, Edge, Brave, Opera, Firefox)
1. Download [`hmlr-devtools-v1.0.0.zip`](./hmlr-devtools-v1.0.0.zip) and extract it to a local folder.
2. Open your browser extension settings:
   - Chrome / Brave: `chrome://extensions/`
   - Edge: `edge://extensions/`
3. Enable **Developer mode** (toggle in top-right corner).
4. Click **Load unpacked** and select the extracted folder (or the `extension/` directory in this repo).
5. Open Developer Tools (<kbd>F12</kbd> or <kbd>Ctrl+Shift+I</kbd>) on any HTMXUI application to see the **⚡ HMLR** tab!

### Option B: Drag & Drop `.crx` (Chromium)
1. Open `chrome://extensions/` with Developer Mode enabled.
2. Drag and drop [`hmlr-v1.0.0.crx`](./hmlr-v1.0.0.crx) directly into the extensions window.
