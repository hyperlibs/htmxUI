Welcome to Hypertext Editor & Studio

Hypertext Editor is an ultra-lean, hypermedia-driven rich text suite designed for modern web applications. It seamlessly unifies document editing with embedded interactive HyperSheet tables and Miro/Figma spatial flowchart capabilities.

💡 ProTip: Type / on any empty line to trigger the slash command launcher, or switch to HyperCanvas Mode in the top-left to design spatial architectures!

HTMX Form Integration

Hypertext Editor connects directly to standard HTMX forms. It updates a hidden content_html payload on every change. 

<!-- HTMX Form Submission -->
<form hx-post="/api/posts/create" hx-target="#post-feedback" class="space-y-4">
  <input type="text" name="title" placeholder="Post Title..." class="w-full px-4 py-2 border rounded-lg">
  
  <!-- Drop-in Hypertext Editor -->
  <div hx-ext="reactive" ...>
    <input type="hidden" name="content_html" id="hypertext-hidden-input">
  </div>

  <button type="submit" class="px-5 py-2.5 rounded-lg bg-primary text-primary-foreground font-semibold">
    Publish Article →
  </button>
</form>

Go DSL Usage

import "github.com/hyperlibs/htmxui/go/components"

// Server-rendered Hypertext Editor with dual-mode HyperText / HyperCanvas studio
editor := components.HypertextEditor(components.HypertextEditorProps{
    Name:        "article_body",
    Placeholder: "Write your story or design architecture...",
    InitialHTML: "<h1>My Journey</h1><p>Start writing here...</p>",
    MinHeight:   "520px",
    WithCanvas:  true,
    WithStudio:  true,
})
