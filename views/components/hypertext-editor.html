Hypertext Editor

A zero-bloat, distraction-free WYSIWYG rich text editor with slash commands (/), floating bubble toolbar, live Markdown/HTML toggles, and seamless HTMX form synchronization.

Welcome to Hypertext Editor

Hypertext Editor is an ultra-lean, hypermedia-driven rich text suite designed for modern web applications. It replaces heavy WYSIWYG packages with zero external dependencies.

💡 ProTip: Type / on any empty line to trigger the slash command launcher!

Designed for Fullstack Developers

Everything you type synchronizes instantly into hidden form fields and updates telemetry in real-time.

  • Zero React, zero ProseMirror, zero bloat
  • Sub-millisecond signal updates via htmx-bolt
  • Native 1:1 Go DSL for server-side HTML rendering

HTMX Form Integration

Hypertext Editor connects directly to standard HTMX forms. It updates a hidden content_html payload on every change. 

<!-- HTMX Form Submission -->
<form hx-post="/api/posts/create" hx-target="#post-feedback" class="space-y-4">
  <input type="text" name="title" placeholder="Post Title..." class="w-full px-4 py-2 border rounded-lg">
  
  <!-- Drop-in Hypertext Editor -->
  <div hx-ext="reactive" ...>
    <!-- Editor content container -->
    <input type="hidden" name="content_html" id="hypertext-hidden-input">
  </div>

  <button type="submit" class="px-5 py-2.5 rounded-lg bg-primary text-primary-foreground font-semibold">
    Publish Article →
  </button>
</form>

Go DSL Usage

import "github.com/hyperlibs/htmxui/go/components"

// Server-rendered Hypertext Editor with placeholder and initial body
editor := components.HypertextEditor(components.HypertextEditorProps{
    Name:        "article_body",
    Placeholder: "Write your story...",
    InitialHTML: "<h1>My Journey</h1><p>Start writing here...</p>",
    MinHeight:   "350px",
})
